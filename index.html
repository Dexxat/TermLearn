Glosario Rápido de Comandos Linux

1. Navegación e Información

pwd: Muestra la ruta actual
ls: Lista archivos y carpetas
ls -la: Lista todo (incluidos ocultos) con detalles
cd <dir>: Cambia de directorio
cd ..: Sube un nivel en el árbol
cd ~: Vuelve a tu carpeta personal ($HOME)

2. Archivos y Carpetas

mkdir <nombre>: Crea un directorio
touch <archivo>: Crea un archivo vacío
cp <orig> <dest>: Copia un archivo
mv <orig> <dest>: Mueve o renombra
rm <archivo>: Elimina un archivo
rm -r <carpeta>: Elimina una carpeta

3. Inspección, Búsqueda y Tuberías

cat <archivo>: Muestra el contenido
head -n 5: Muestra las primeras 5 líneas
grep <texto>: Busca líneas con ese texto
|: Conecta la salida de un comando a otro
>: Guarda la salida en un archivo (sobrescribe)
>>: Agrega la salida al final del archivo

4. Permisos, Procesos y Servicios

chmod +x <file>: Da permisos de ejecución
ps aux: Muestra procesos activos
kill <pid>: Finaliza un proceso por su ID
curl <url>: Hace una petición HTTP
